# Interactive Task Management System - Full Module

This repository contains the evolution of a task management application developed over four weeks. Each week represents a significant step forward in functionality, moving from basic JavaScript logic to a fully integrated REST API system with persistent storage.

## Project Evolution Journey

### Week 1: Basic Logic and Consolidation
The first week focuses on the core logic of the application. It establishes the initial data structures and basic functions to handle tasks using vanilla JavaScript.
- Key concepts: Variables, arrays, and basic functions.
- Goal: Create a functional script that handles task data in the console.

### Week 2: Functions and Control Structures
In the second week, the logic is refined by implementing more complex functions and control structures.
- Key concepts: Array methods (push, filter, map), conditional statements, and improved data handling.
- Goal: Optimize the task management logic for better performance and readability.

### Week 3: DOM Manipulation and Local Persistence
The third week introduces the user interface and local data storage. The application moves from the console to the browser.
- Key concepts: DOM API (createElement, removeChild), event listeners, and localStorage.
- Goal: Allow users to interact with the application through a web interface and save data locally in the browser.

### Week 4: API Integration and Asynchronous Programming
The final week completes the evolution by connecting the frontend with a backend simulation (JSON Server) and implementing advanced asynchronous patterns.
- Key concepts: Fetch API, async/await, try/catch, and full CRUD operations (GET, POST, PUT, DELETE).
- Goal: Create a professional-grade application that synchronizes local state with a server and handles errors gracefully.

## How to Navigate This Repository

1. Browse through the folders `semana1` to `semana4` to see the code changes and improvements.
2. Each folder contains its own Readme file with specific instructions for that week.
3. For the most complete version of the project, refer to the `semana4` directory.
