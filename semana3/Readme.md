# Interactive Task System - Week 3

A client-side task management application focused on DOM manipulation and local data persistence.

## Features

- Dynamic DOM Manipulation: Add and remove tasks without reloading the page.
- Persistent Storage: Tasks are saved in the browser using localStorage.
- Event Handling: User interactions managed through JavaScript event listeners.
- Real-time Updates: The task list refreshes instantly after any change.
- Form Validation: Prevents adding empty tasks to the list.

## Technologies Used

- HTML5: Page structure and semantic elements.
- CSS3: Layout and custom styling using Flexbox.
- JavaScript (ES6): Logic for task management, DOM API, and localStorage.

## Installation and Usage

1. Clone or download the repository.
2. Navigate to the project folder:
   ```bash
   cd "interactive system/semana3"
   ```
3. Open the file `manipulacion_dom.html` in any modern web browser.

## Project Structure

- manipulacion_dom.html: The main entry point and user interface.
- app.js: Logic for adding, deleting, and storing tasks.
- style.css: Visual design and layout.
- img/: Icons and image assets.
- tipografy/: Custom fonts used in the project.

## Technical Overview

The application demonstrates fundamental JavaScript concepts:
- Selecting elements using document.getElementById and querySelector.
- Creating and removing DOM nodes dynamically with createElement and removeChild.
- Storing data as JSON strings in the browser's localStorage.
- Iterating through arrays to render the UI based on stored data.
